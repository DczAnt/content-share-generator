# 统一叙事公式 + 曝光规范

## 统一叙事公式（所有平台所有选题套用）

```
skill 是什么/怎么用（主体，技术分享定位）
    → 能避免什么坑（挑 1-3 条具体的，取自 fact-base §三，代码级讲透）
    → 项目实测数据当证据（84.27fps / 双核 61%+60% / 4.2×，背书不喧宾夺主）
    → 引导动作（统一指向 GitHub 仓库）
```

**技术分享定位的三条写作原则**：
1. **结论前置**：读者 10 秒内知道能带走什么（一个坑的解法 / 一条决策树 / 一套方法论）。
2. **可复现**：命令可直接复制执行，代码可直接粘贴编译，不给"大概是这个意思"式的伪代码。
3. **数字说话**：每个优化论断配实测数据，没有数据不下结论。
