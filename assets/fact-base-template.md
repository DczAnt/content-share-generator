## 提炼指南（AI 现场提炼时遵循）

1. **读源**：目标 skill 的 `SKILL.md`（frontmatter description + 工作流 + 陷阱清单）+ `references/` 目录名 + 仓库 `README.md`（若有）
2. **填 §一**：从 frontmatter 和 README 提取产品事实；仓库地址从 git remote 或 README 获取
3. **填 §三**：从 SKILL.md 的"陷阱清单"节逐条转写为四段式；若 skill 没有显式陷阱清单，从 references 文档中归纳高频"注意事项/坑"
4. **填 §五**：每条陷阱派生一个选题（"X 坑排查实录"），再加 1-2 条方法论选题（"我把 X 做成了 AI 技能包"）
5. **存档**：写到 `fact-bases/<skill名>.md`，后续直接复用
