板子报 GLIBC_2.34 not found
怎么办？

先量：ldd --version  # 板子上跑
glibc < 2.34（如 2.31）

容器 2.35 直编 → 必崩

产物埋了 2.34 符号引用，板子没有这个符号
✗ ./demo
version `GLIBC_2.34' not found
解法 A：对齐工具链

用板子 sysroot 的 crt 三要素

-nostartfiles + 板子 Scrt1.o/crti.o/crtn.o + --sysroot
✓ g++ --sysroot=board_fs \
  -nostartfiles board/Scrt1.o ...
解法 B：静态链接

-static 兜底，零 libc 依赖

体积大但任何板子都能跑，不依赖厂商 .so 时首选
✓ g++ -static -o demo demo.cpp
not a dynamic executable
