# 朋友圈图文模板

## 产出物结构（按此顺序输出成品）

1. **正文文案**（直接复制可发）
2. **配图清单**（每张图的内容+标注要求）
3. **发布技巧**（时间/折叠/评论回复模板）

## 正文结构骨架

```
第 1 行（钩子，折叠前必须吊住人）：奇葩坑/反差事实/硬核数字开头
第 2-3 段（故事或干货主体）：现象→排查→真相；或清单式干货
第 4 段（升华落点）：沉淀进 skill / 数字背书
（空行）
**https://github.com/DczAnt/rk3xx-chip-dev**   ← 加粗、单独成行、倒数第二行
（空行）
结尾互动（提问式，引导评论）
```

- 篇幅：120-250 字为宜；前 6 行是折叠区，钩子必须在前 3 行
- 语气：技术同行的"踩坑复盘"口吻，不用营销腔

## 配图规范

- 3 张（故事型）或 9 张（全景型）；第 1 张决定打开率
- 截图必须打码内网 IP；skill 目录画面只用公开仓内容
- 全景型必留 1 张"仓库首页 + 大字地址"固定位

## 自检清单

- [ ] 前 3 行有钩子（折叠前看得见）
- [ ] GitHub 地址单独成行加粗、倒数第二行
- [ ] 数字与 fact-base.md 一致
- [ ] 截图无敏感信息
- [ ] 结尾有互动问题
- [ ] 读者能带走至少 1 个知识点
